# Emby 演员图片同步工具（emby-actors）

以媒体库 NFO 中的演员信息为准，把演员头像同步到 Emby 的 people 目录。

## 工作方式

1. 递归扫描媒体库（默认 `E:\Media`）下所有 `.nfo`，提取 `<actor>` 标签
2. 有 `<thumb>` 链接的演员按 `tmdbid` 去重聚合；**无链接的演员不处理**
3. 下载时把链接中的尺寸段（如 `/t/p/h632/`）替换为 `/t/p/original/`，获取原图；
   **绝不修改任何 NFO 文件**
4. 保存为 Emby 标准命名：`{名字首字符}/{演员名}-tmdb-{id}/folder.jpg`
   （例：`克/克丽丝滕·威格-tmdb-41091/folder.jpg`）
5. 用 SQLite（默认项目根目录 `people.db`）记录已下载状态：
   - **首次运行**：数据库为空，已有旧图（之前用 h632 链接下载的）会全部重新下载替换
   - **之后运行**：只下载新增演员、链接变化或文件缺失的图片
6. 清理：people 目录下在媒体库 NFO 中已不存在的演员目录会被删除；
   NFO 中仍有但名字与目录名不一致的，按媒体库重建

## 用法

```bash
uv run emby-actors                 # 完整同步
uv run emby-actors --dry-run       # 只显示计划，不下载不删除
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--media-dir` | `E:\Media` | 媒体库目录 |
| `--people-dir` | `D:\embyserver\programdata\metadata\people` | Emby 演员图片目录 |
| `--db` | 项目根目录 `people.db` | SQLite 数据库路径 |
| `--rate` | `2.0` | 起始请求速率（张/秒），成功后动态提升 |
| `--max-rate` | `8.0` | 速率上限（张/秒） |
| `--workers` | `8` | 并发下载线程数 |
| `--retries` | `3` | 失败重试次数（429 会等待后重试） |
| `--limit N` | 0（不限） | 只下载前 N 张（测试用） |
| `--dry-run` | — | 只显示计划 |

## 速率自适应

下载是多线程并发 + 全局自适应限速：每次成功速率 +3%（逐渐向 `--max-rate` 提升），
遇到 429 限流立即减半并等待，其它错误小幅降速。进度条后缀会实时显示当前速率。
想更快可调高 `--workers` / `--max-rate`；想保守可调低。

## 注意事项

- 下载失败会打印明细并以退出码 1 结束；直接重跑即可续传（已成功的不会重复下载）
- 中断（Ctrl+C）安全，重跑从断点继续
- 程序只管理 people 目录下 `{名}-tmdb-{id}` 格式的目录，其它目录不动
